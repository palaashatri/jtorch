# JTorch icon family

New dimensional torch flame over sculpted Java `J`, designed to distinguish this Java tensor-computing library from generic grid diagrams. Includes transparent source crop, 16–1024px PNG exports, ICO, ICNS, wordmark and social artwork. All large rasters are scaled from a common ~248px icon crop of the image-generated concept sheet, **not** original 1024px masters. Draft for visual review and small-size QA before runtime integration; not merged.
